# Sound cues

User-selectable cues, one file per `<kind>-<id>.wav` (see
`shared/sound-catalog.ts`):

- **complete-** (session finished → waiting): chime, soft, marimba, arp, bell
- **alert-** (needs you → blocked / errored): double, triple, knock, pingpong

All are **synthesized originals** generated by `scripts/gen-sounds.mjs` (sine /
triangle / FM + envelope). They carry no license obligations — free to bundle,
ship, and modify. Regenerate with `node scripts/gen-sounds.mjs`.

## Swapping in your own

Replace any `<kind>-<id>.wav` (keep the filename) with a redistributable,
**commercial-OK** clip:

- **Kenney.nl** — Interface Sounds / UI Audio — CC0 (public domain)
- **Pixabay** — pixabay.com/sound-effects — royalty-free, no attribution
- **Mixkit** — mixkit.co/free-sound-effects — no attribution
- **Freesound.org** — filter to the CC0 license

Keep clips short (< 0.6s) and quiet (normalized to ~ -2 dBFS) so they read as
subtle cues, not alarms. To add a NEW option, add it to the catalog, the
generator (or drop in a file), and it appears in the Settings dropdown.
